FAQ

Questions

Is it really free?

The app is free and open source (MIT). The AI comes from the Claude or ChatGPT plan you already have, through their official CLIs, so there's no extra cost. With a local model through Ollama, it costs nothing at all.

Do I need an API key?

No. Babelpen drives the claude or codex CLI you're logged into, and deliberately removes API keys from its environment so it never switches to pay-per-use billing.

Which languages does it support?

Any language the model knows. You set the languages you write in as hints, and text is always fixed in its own language. The interface comes in English, Portuguese, Spanish, French, German and Italian.

Which apps does it work in?

Any native or web text field on macOS: Slack, Gmail, Notion, GitHub, Linear, Discord, WhatsApp, Notes, Mail, Chrome, Safari and more. It reads the field through macOS Accessibility, so there's no extension to install per browser.

Is it fast?

With Claude Code, Babelpen keeps one warm process, and a small model like Haiku answers in about 0.7 seconds on short messages. Codex takes a few seconds per review.

How is it different from Apple's Writing Tools?

Writing Tools wait for you to select text and ask. Babelpen reviews as you pause, shows a diff of exactly what changes, respects your vocabulary, translates what you read, and runs on the model you choose.

Windows or Linux?

Not yet. Babelpen is a native macOS app (macOS 13 or later, Apple Silicon and Intel).
